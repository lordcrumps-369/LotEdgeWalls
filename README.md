# TS2-LotEdgeWalls v1.0

An AI-assisted ASI plug-in for The Sims 2 that changes build-mode placement rules at lot boundaries.

## Source and download

This folder contains the source, tests, and build scripts for the v1.0 ASI distributed on SimFileShare. The main implementation is in [plugin.cpp](plugin.cpp). [Download TS2-LotEdgeWalls v1.0 on SimFileShare](https://simfileshare.net/download/6305671/).

Place TS2-LotEdgeWalls.asi inside either TSBin or TSBin\Mods depending on your setup!
